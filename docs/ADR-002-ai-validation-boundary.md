# ADR-002: AI recommendations never execute directly

## Status

Accepted - 2026-09-09

## Context

Future rule recommendations may be generated by an LLM, but quality decisions must be auditable and reproducible.

## Decision

The MVP only profiles data. In the AI milestone, a provider adapter will return structured candidate data to one Pydantic and semantic-validation path. Candidates will remain proposed until a human approves them; a deterministic rule engine will execute only approved, validated typed rules.

## Consequences

No raw model output, code, SQL, or arbitrary regular expression will enter execution. The default demo path will use a deterministic fake provider, enabling test and demo runs without API credentials.
